# Mulch project input checklist

Gather these inputs before estimating:

## Areas

- [ ] Give every bed or zone a name.
- [ ] Record each shape: rectangle, square, or circle.
- [ ] Measure length and width for rectangles.
- [ ] Measure one side for squares.
- [ ] Measure diameter for circles.
- [ ] Record the unit used for each measurement.
- [ ] Choose a separate depth for every area.

## Material

- [ ] Decide whether the purchase unit is bags or bulk volume.
- [ ] If buying bags, record the volume printed on the bag.
- [ ] If buying bulk, confirm whether the supplier sells by cubic yard or cubic meter.
- [ ] Ask the supplier about minimum order quantities.

## Cost inputs

- [ ] Get a current material quote for the selected product.
- [ ] Confirm whether delivery is flat-rate, distance-based, or included.
- [ ] Confirm the labor unit: per square foot, per cubic yard, hourly, or project total.
- [ ] Check whether bed preparation, weed removal, edging, cleanup, taxes, and disposal are included.
- [ ] Record the quote date and service area.

## Final check

- [ ] Recheck dimensions before ordering.
- [ ] Confirm vehicle and wheelbarrow access.
- [ ] Keep estimate assumptions with the supplier or contractor quote.
